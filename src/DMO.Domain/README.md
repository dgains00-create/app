# DMO.Domain

Domain-level primitives only.

## P1-T01 status

Deliberately almost empty.

Phase 1 forbids pre-modelling USER, ADMIN, Template, Module, Tool, Job On, Controlo or any
industrial entity merely to prepare for later tasks. No such type exists here yet.

P1-T02/T03 introduce the application account model. A domain type is added here only when a
concrete task genuinely requires it — not in advance.
